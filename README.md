# きらりんフォトコレクション（Web版）

日向坂46 四期生・竹内希来里さんの生写真を、シリーズ・カットごとに「所持／未所持」でチェックする個人用Webアプリ（PWA）です。
iPhoneのSafariからホーム画面に追加して使えます。非公式の個人用アプリで、日向坂46運営・メンバー本人とは関係ありません。

公開予定URL：https://ponchan712.github.io/kirari-photo-collection/

## 機能

- 135シリーズ（`data/series.json`、ID `KIR-001`〜`KIR-135`）
- 全シリーズ共通の4カット（ヨリ・チュウ・ヒキ・座り）の所持チェック（タップで所持⇔未所持、操作のたびに自動保存）
- シリーズ別コンプリート率（0・25・50・75・100%、4カット所持でCOMPLETE）、全体コンプリート率（分母540種類）
- シリーズ名の検索、カテゴリー別表示（発売年は元データにないため、年の絞り込みはデータがある場合のみ表示）
- 未所持写真の一覧
- JSONバックアップ・復元（確認画面あり／旧形式・旧番号・HTML試作版・Androidアプリ版のバックアップも変換して読込可）
- オフライン対応（Service Worker）

## シリーズデータ

- `data/kirari_seed.json`：2026-10-19のユーザー提供一覧（137件）を無加工で保存した整理前の初期データ
- `data/series.json`：2026-10-23に整理した現在の一覧（135件）。旧ID→新IDの対応表（`id_map`）を含む
  - 削除：旧KIR-091「【未確定】Love yourself! MVA#」、旧KIR-093「【未確定】読晝コーデ」
  - 移動：「読書コーデ」（旧KIR-103）を旧KIR-093の位置へ（新KIR-092）
- 保存済みの所持チェックは起動時に一度だけ新しい番号へ移行し、移行前のデータはブラウザ内の専用領域に保管します。

## データの保存

- チェック状態はブラウザの IndexedDB に保存し、localStorage にも同じ内容を保存しています。
- 端末間の自動同期はありません。ブラウザのデータ削除で消えるため、定期的にJSONバックアップを保存してください。
- iPhoneでは、Safariで開いたページとホーム画面のアプリは保存場所が別です。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面（iPhone用のメタ情報を含む） |
| `css/style.css` | デザイン（空色・白、セーフエリア対応） |
| `js/core.js` | データ・集計・保存・バックアップ |
| `js/app.js` | 画面の処理 |
| `data/series.json` | 現在のシリーズ一覧（135件・旧ID→新IDの対応表つき） |
| `data/kirari_seed.json` | 整理前の初期データ（提供JSONを無加工でコピー・137件） |
| `manifest.webmanifest`・`icons/` | PWA設定・ホーム画面アイコン |
| `sw.js` | オフライン用キャッシュ |
| `.nojekyll` | GitHub Pagesでそのまま配信するための設定 |

ファイルはすべて相対パスで参照しているため、`/kirari-photo-collection/` のようなサブディレクトリでも動作します。
更新時は `sw.js` の `VERSION` を上げてください（オンライン時は常に最新ファイルを取得します）。
